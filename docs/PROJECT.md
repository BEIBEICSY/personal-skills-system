# Project

## Name

陈贝贝个人 Skills 管理仓库

## Goal

盘点、维护、验证和迁移属于自己的 Skills，使个人 AI 能力可以持续迭代，并在更换 Agent、客户端、账号或电脑时恢复。本仓库管理档案和更新机制，不集中接管 Skill 源码。

## Workspace profile

`code（代码与配置资产）`

## Primary audience

贝贝本人。项目首先服务个人工作与生活，不以通用产品或公开 Skill 市场为第一目标。

## Primary inputs

- 已有的自制或深度定制 Skills。
- 每个 Skill 的安装状态、使用场景、依赖和规则源。
- 真实任务试跑结果、失败记录与人工修正。

## Expected outputs

- 可核验的个人 Skills 总表。
- 每个 Skill 的独立维护档案，以及权威来源、安装入口和维护状态。
- 统一的登记、验证、迭代、迁移与恢复规则。
- 后续需要时加入的盘点、校验或同步脚本。

## First milestone definition of done

- 工作区启动、心理咨询、记账三个 Skill 都进入总表，并各有独立档案目录。
- 已找到的路径均经过存在性检查；未找到的项目明确标为 `待核验`。
- 项目具有唯一的 `AGENTS.md`、明确的状态文件、决策记录和历史记录。
- 不写入明文凭证、个人账单、心理咨询原始内容、重要沟通原文或其他敏感数据。

## Scope boundaries

- 本项目先做个人 Skills 的管理中枢，不默认复制或接管所有 Skill 源码。
- 外部通用 Skill、插件和 MCP 作为依赖或候选资产管理，除非用户明确把它纳入个人定制范围。
- 修改、迁移、安装或卸载具体 Skill，需要独立任务和验证。
- 不以聊天记忆作为权威记录。
