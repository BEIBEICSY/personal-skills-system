# reviewing-important-conversations

整理并复盘重要的非心理咨询沟通，把忠实材料与后续理解分开。

## 用途与场景

- 适用场景：老板 one-on-one、同事协作、朋友深聊、伴侣和家庭沟通等；用户要求归档、转写、复盘、跟进或更新关系／自我脉络。
- 不适用场景：明确属于心理咨询时停止本流程，改用 [`reviewing-therapy-transcripts`](../reviewing-therapy-transcripts/)。不得同时更新沟通脉络与心理咨询价值观脉络；用户明确允许且来源确实相关时可以相互引用，但不自动复制、合并或把一套结论归入另一套。
- 维护边界：可安装内容在 [`package/`](package/)。不保存录音、截图、聊天导出、转写、复盘产物或关系脉络原文。
