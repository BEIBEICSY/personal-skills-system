# reviewing-important-conversations 恢复

## 前置条件

- 已确认权威来源，或明确以当前安装目录为临时来源。
- 目标 Agent 的 Skills 目录可写。
- 恢复过程不复制录音、截图、聊天导出、转写、复盘产物或关系脉络到本仓库。

## 恢复步骤

1. 从确认后的权威来源取得 Skill。独立源项目待核验前，可临时使用当前安装目录。
2. 同时安装 `SKILL.md` 与同目录 `templates.md`。
3. 读取入口，确认名称、核心原则、权力关系和完成前核对仍在。
4. 只验证规则结构。不要为了验证而把私人沟通材料提交到本仓库。
5. 第一次实际使用前，确认用户指定的沟通复盘工作区；不得写入心理咨询目录或本管理仓库。

## 恢复后验证

- 入口文件与 `templates.md` 可读。
- 与 `reviewing-therapy-transcripts` 的分流规则仍在。
- 本仓库没有新增私人沟通原文。

## 人工介入点

- 真实整理只在用户提供材料并指定存储位置后进行。
- 对象标识默认使用“关系＋称呼”；真实姓名需用户明确允许。
- 跨设备路径需要本地覆盖，不能直接复用本机绝对路径。
