# bill-to-suishouji

将支付宝、微信账单清洗并写入随手记导入模板。

## 用途与场景

- 适用场景：把支付宝 / 微信账单或已合并账单转成随手记导入 xls，并按个人分类和账户体系处理。
- 不适用场景：不要用本仓库保存账单、导入文件或账户明细。
- 维护边界：本目录只保存管理档案。权威规则源仍在随手记项目，本仓库不复制源码或账单。
