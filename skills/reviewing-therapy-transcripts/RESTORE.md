# reviewing-therapy-transcripts 恢复

## 前置条件

- 已确认权威来源，或明确以当前安装目录为临时来源。
- 目标 Agent 的 Skills 目录可写。
- 恢复过程不复制逐字稿、咨询笔记或复盘产物到本仓库。

## 恢复步骤

1. 从确认后的权威来源取得 Skill。独立源项目待核验前，可临时使用当前安装目录。
2. 安装到目标 Agent 的 Skills 目录。
3. 读取入口 `SKILL.md`，确认名称、基本边界和输出前自检仍在。
4. 只验证规则结构。不要为了验证而把私人逐字稿提交到本仓库。

## 恢复后验证

- 入口文件可读。
- 非诊断边界和工作假设规则仍在。
- 本仓库没有新增私人咨询原文。

## 人工介入点

- 真实复盘只在用户主动提供逐字稿时进行。
- 复盘产物应保存在用户指定的外部工作区，不进入本管理仓库。
- 跨设备路径需要本地覆盖，不能直接复用本机绝对路径。
