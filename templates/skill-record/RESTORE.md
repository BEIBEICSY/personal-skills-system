# example-skill 恢复

## 前置条件

- 已确认权威来源，或明确以当前安装目录为临时来源。
- 目标 Agent 的 Skills 目录可写。
- 不把私人原始数据或凭证复制进本管理仓库。

## 恢复步骤

1. 取得权威来源或已核验的安装副本。
2. 安装到目标 Agent 的 Skills 目录。
3. 读取入口 `SKILL.md`，确认名称与描述。
4. 执行一次不涉及私人原始数据的安全预览或最小检查。

## 恢复后验证

- 入口文件可读。
- 触发描述与关键边界仍在。
- 如有项目测试，在权威项目目录运行，不把测试输入提交到本仓库。

## 人工介入点

- 跨设备路径需要本地覆盖。
- 账号授权只核验位置，不记录明文。
- 真实任务试跑结果由维护者确认后再写入 `HISTORY.md`。
